## 4. 「输入即搜索」原理答疑（只讲，未改代码）

用户问「别人搜完直接出结果，是不是钩子函数」。结论：**不是生命周期钩子，是 `watch` 侦听器**。
现状：搜索框均为 `@keyup.enter="fetchData"`（DrugList:26 等），要手动回车。

**方案要点（以后要做时照这个来）**：
```js
import { ref, reactive, watch, onUnmounted } from 'vue'
let timer = null                       // 必须放 watch 外，放里面等于没防抖
watch(searchName, () => {
  clearTimeout(timer)                  // 撤销上一次待执行
  timer = setTimeout(() => {
    page.value = 1                     // 最易漏！否则在第 5 页搜索会返回空表
    fetchData()
  }, 300)
})
onUnmounted(() => clearTimeout(timer))
```
- 必须配**防抖**：不防抖会每敲一字发一次请求，且存在**竞态**（请求 2 晚于请求 4 返回 → 列表显示「阿莫」而非「阿莫西林」）
- `watch` 优于 `@input`：代码里赋值也能触发 → 重置按钮只需 `searchName.value = ''` 一行，列表自动刷新（顺带解决上表问题 A 的重置按钮）
- 下拉框保持 `@change` 即可，无连续输入问题
- 项目**无需引入 lodash**（package.json 无，手写 5 行足够）；若 8 页都加，抽 `src/composables/useDebounce.js`
- 涉及页面：药品/患者/医生/病历 4 个搜索框；顺便给 `BillList:26` 补 `@change="fetchData"` 统一行为

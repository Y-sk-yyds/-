# 2026-08-04 工作日志

## 移动端 H5 患者服务

新增 3 个文件，后端 1 个 Controller + 3 个 API，前端 2 个 Vue 页面：

### 后端
- `MobileController.java` — 免登录公共 API（`/api/mobile/**`）
  - `GET /api/mobile/schedules` — 排班列表（含医生姓名科室）
  - `POST /api/mobile/registrations` — 手机挂号（phone + scheduleId）
  - `GET /api/mobile/my-data?phone=` — 我的全部数据（挂号+账单+病历+排队）
  - `PUT /api/mobile/bills/{id}/pay` — 手机支付
- `SecurityConfig.java` — `/api/mobile/**` 加入 permitAll

### 前端
- `MobileHome.vue` — 排班挂号：日期选择 + 医生卡片 + 挂号弹窗 + 挂号成功
- `MobileRecords.vue` — 我的就诊：挂号列表 + 排队看板 + 病历 + 支付
- `router/index.js` — 两路由 `/mobile` `/mobile/records`，免登录通行
- `api/index.js` — 新增 mobileApi

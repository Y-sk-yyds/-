## 挂号列表排序修复 ✅
- RegistrationMapper.xml: `ORDER BY r.queue_num ASC` → `ORDER BY s.work_date ASC, r.queue_num ASC`
- 先按排班日期，同天按排队号，避免跨日排序混乱

## 排班管理问题修复 ✅
ScheduleController.java 修了 4 个问题：

1. **编辑丢失 remainNum（严重 bug）**
   - 原因：前端编辑表单无 remainNum 字段，updateById 直接覆盖为 null
   - 修复：先从 DB 取已有记录，只合并可编辑字段，保留正确的 remainNum

2. **防止重复排班**
   - 创建时检查同一 doctorId + workDate + period 是否已存在

3. **总号源变化联动 remainNum**
   - delta = newTotalNum - oldTotalNum
   - remainNum = max(0, min(oldRemainNum + delta, newTotalNum))

4. **删除校验已有挂号**
   - 注入 RegistrationMapper，delete 前检查 status=1 的挂号记录，有则拒绝

5. **注释修正**
   - scheduleDate/timeSlot/fee → workDate/period/totalNum/status

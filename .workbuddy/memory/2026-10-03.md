## ③ 处方开方「药品临期提醒」—— 新增 3 个月预警线（同日完成并实测）

### 用户诉求
> "处方开具这里，因为药品快过期医生也是不太方便经常去看的，所以要设置一个提示，
> 自动反应不能开这个药，时间是分段的，离过期时间少于3个月要提醒医生时间还有多少天。"

追问后确认：**"可以开，但是要提醒。"**（31~90 天可开，30 天以内维持硬禁止）

### 设计：两级效期管控（预警线与下架线彻底分离）
| 剩余天数 | 级别 | 行为 |
|---|---|---|
| &lt; 0（已过期） | `EXPIRED` | 自动下架 + 禁止开具 |
| 0 ~ 30 | `NEAR` | 自动下架 + 禁止开具（**原有逻辑，一行未动**） |
| 31 ~ 3 个月 | `WARN` | **可开具**，医生界面黄色提示「还有 X 天过期」 |
| &gt; 3 个月 | `NORMAL` | 正常 |
| 未登记效期 | `UNKNOWN` | 不提示 |

### 改动（后端 3 + 前端 1，**未加任何数据库列**）
- `DrugExpiryScheduler`：新增常量 `EXPIRY_WARN_MONTHS = 3`，与 `NEAR_EXPIRY_DAYS = 30` 并列 —— **两条线各管各的**
- `Drug` 实体：新增两个 `@TableField(exist = false)` 瞬态字段 `daysToExpire`(Long) / `expiryLevel`(String)
- `DrugService.fillExpiryInfo(Drug)`：由 `expireDate` 算剩余天数并判级别，**阈值全部取自 `DrugExpiryScheduler`**
  → 阈值只由后端一处决定，前端纯展示（P8 吃过"阈值散落三处"的亏，这次不再重蹈）
- `PrescriptionList.vue`：
  - `drugLabel(d)` —— 下拉文案 WARN 药显示 `名称 (¥价) ⚠️ 还有 X 天过期`
  - `drugExpiryTag()` —— 药品行内黄色 tag
  - `nearExpiryDrugs` + `ElMessageBox.confirm` —— 提交前二次确认（可开，但要医生点一下头）
  - 顺手修瑕疵：下拉改用 `availableDrugs`（只列 `status=1`）；原先 `pageSize:200` **不传 status，会把已下架的药也列进选项**
